                                   📁 Flask Portfolio Website

🌟 Project Overview

               This project is a simple personal portfolio website created using Flask, HTML, and CSS. 
               It introduces the student, highlights skills, and displays contact information through a clean and responsive web page.

🎯 Project Objective

               The main objective is to learn how Flask works with HTML templates and CSS styling to build a basic web application.
